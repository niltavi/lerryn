# Start work in a Niltavi repository

Read these sources before proposing or editing a change. Use an up-to-date checkout or authorized repository access.

1. Read the current [Niltavi Rules](https://github.com/niltavi/niltavi-rules#readme) and identify the sections that govern the requested change.
2. Read the [Niltavi Skills index](https://github.com/niltavi/niltavi-skills#readme) and open the `SKILL.md` for each applicable workflow.
3. Read the [Niltavi UI README](https://github.com/niltavi/niltavi-ui#readme). For interface work, also read the relevant shared theme, components, templates, and examples before choosing an implementation.

Read the repository's `AGENTS.md` and any guidance for the affected paths. Apply the current shared rules to the proposed change and verify the relevant acceptance checks before handing it back. If a required source is inaccessible or local guidance conflicts with a shared rule, surface the specific issue before making the affected change.
