# DM Sans

Unmodified Latin WOFF2 files from `@fontsource/dm-sans` 5.3.0, already used by the web console. Source: https://github.com/fontsource/fontsource/tree/main/fonts/google/dm-sans. Copyright and SIL Open Font License 1.1 are preserved in `OFL.txt`.

# Cormorant Garamond

Unmodified Latin WOFF2 files (400 and 500, normal and italic) from `@fontsource/cormorant-garamond` 5.3.0, the display serif of the Niltavi brand. Source: https://github.com/fontsource/fontsource/tree/main/fonts/google/cormorant-garamond. Copyright and SIL Open Font License 1.1 are preserved in `OFL-Cormorant.txt`.
